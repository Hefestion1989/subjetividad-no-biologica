## Experiencia interactiva
Se añadió una interfaz simple para personas que buscan una ruta formativa (profesional o técnica) con filtros de intereses y modalidad.

- Archivo: `interfaz-orientacion.html`
- Cómo verla: abrir el archivo en un navegador o servir el proyecto localmente con `python -m http.server 8000` y entrar a `http://localhost:8000/interfaz-orientacion.html`.
